## 这是什么

一个**单文件网页应用**，把网上好用的免费工具聚合到一个页面里 —— OCR 识别、PDF 处理、
PPT 模板与 AI 生成、公众号排版、影视资源、音乐下载与 AI 音乐、国际新闻、热点榜单、
企业查询、浏览器插件、免费图库、临时邮箱……

纯原生 HTML + CSS + JS，**零第三方依赖、零构建步骤**，克隆下来双击就能用。

## 快速开始

### 方式一：在线使用（最省事）

直接打开 https://chenzhuanxin.github.io/free-tools-nav/

### 方式二：本地运行（功能最完整）

```bash
git clone https://github.com/chenzhuanxin/free-tools-nav.git
cd free-tools-nav
python serve.py
```

浏览器会自动打开 `http://127.0.0.1:8765/`。

- ✅ M3U8 聚合搜索**开箱即用**，无需任何代理配置
- ✅ Excel 导出为**标准 .xlsx**（无格式警告，含表头样式、冻结首行、自动筛选）

### 方式三：直接双击 `index.html`

零依赖可用，但受 `file://` 协议限制，聚合搜索不可用、Excel 为兼容格式。

## 关于 M3U8 聚合搜索的跨域问题

这是本项目最需要注意的一点。放在 **GitHub Pages** 这类静态托管上时，
浏览器同源策略会拦截大部分资源站接口。

实测（2026-10-07）7 个可搜索资源站中：

| 站点 | 接口状态 | 浏览器可直连 |
|---|---|---|
| 量子资源 | ✅ 200 | ✅ 有 `Access-Control-Allow-Origin: *` |
| 光速资源 / 红牛资源 / 360 资源 / 最大资源 / 爱奇艺资源站 / 金鹰资源 | ✅ 200 | ❌ 无 CORS 头，需代理 |

因此页面内置了**四级降级**策略：

1. **自建代理** —— 点页面里的 **⚙ 代理设置**，填入自建 Cloudflare Worker 地址（最稳）
2. **本地代理** —— 通过 `serve.py` 打开时的 `/api/proxy`
3. **直连** —— 少数接口带 CORS 头，可直接读取
4. **公共 CORS 代理** —— 仅剩 allorigins 可用且会限流，作最后兜底

> 免费部署自建代理只需 2 分钟，且**不需要域名和信用卡**（Cloudflare Workers 免费额度 10 万次/天）。
> 详见 [`proxy/README.md`](proxy/README.md)。

## 自定义数据

`tools-data.js` 是纯文本，用记事本就能改：

```js
window.TOOL_DATA = [
  {
    id: "office", name: "办公文档", icon: "📄", color: "#4f7cff",
    groups: [
      {
        id: "ocr", name: "OCR 文字识别", icon: "🔍",
        tools: [
          { name: "工具名", url: "https://…", desc: "一句话说明",
            tags: "标签1,标签2", free: "完全免费" }
        ]
      }
    ]
  }
];
```

| 字段 | 说明 |
|---|---|
| `name` / `url` | 工具名称、网址（必填） |
| `desc` | 一句话说明 |
| `tags` | 逗号分隔的标签（最多显示 3 个） |
| `free` | 免费说明，含「完全免费」时显示绿色标签 |
| `api` | 采集接口地址，填写后显示 API 标签并可参与聚合搜索 |
| `nosearch` | `true` 表示该接口不支持关键词搜索（仅导航，不参与聚合） |

在 `groups` 数组里再加一个对象，页面就会出现新的可折叠二级分类。

## 技术说明

- **零第三方依赖** —— 前端纯原生 JS / CSS，无框架、无 CDN、无构建步骤
- **标准 xlsx 生成** —— `serve.py` 用 `zipfile` 手写 OOXML，无需 openpyxl 等库
- **本地代理** —— `serve.py` 内置目标域名白名单，不会被当成开放代理
- **数据持久化** —— `localStorage`，键名 `free_tools_nav_v2`
- **兼容性** —— 现代浏览器（Chrome / Edge / Firefox / Safari）

## 链接可用性说明

收录的 240 个链接均经过程序化探活 + 人工复核，已剔除失效项（如已停服的新媒体管家、
九酷音乐网、Tome）。部分站点探测失败属于**正常现象**：

- **反爬拦截**（403/412/521）：Pexels、Pixabay、国家企业信用信息公示系统等，浏览器可正常打开
- **国内网络限制**：GreasyFork、Wallhaven、Suno、Gamma、Unsplash 等需科学上网

详见 [`AUDIT.md`](AUDIT.md)。
