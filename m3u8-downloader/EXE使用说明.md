# 🎞️ M3U8 下载器 · EXE 使用说明

> 适用版本：**v1.0.0** ｜ 文件：`M3U8下载器.exe`（约 17 MB）
> 设计：**公歧子**　微信：**gongqizi0**

这是一个**免安装、双击即用**的影视资源搜索下载工具。不用装 Python、不用配置环境，解压后直接双击就能用。

## 一、快速上手（3 步）

### 第 1 步：下载并解压

1. 在 Release 页面下载 `M3U8下载器.exe`
2. 放到一个**有足够空间的盘**（建议 D 盘等非系统盘），例如 `D:\M3U8下载器\`
3. 首次运行 Windows 可能弹出 **SmartScreen「已保护你的电脑」** 提示 —— 这是未签名小工具的常见提示，点 **「更多信息」→「仍要运行」** 即可

> 💡 **为什么会被拦？** 因为 EXE 没有购买数字签名证书。程序完全离线运行、不联网上传任何数据，只访问你指定的资源站接口。

### 第 2 步：双击运行

双击 `M3U8下载器.exe` → 会弹出黑色命令行窗口（**请勿关闭**，它就是程序本体）→ 浏览器**自动打开**操作界面。

如果浏览器没自动打开，手动访问窗口里显示的地址，形如：

```
http://127.0.0.1:8899/
```

> 程序会自动挑一个空闲端口（8899 / 9000 / 9123 / 9527 / 18080），窗口里会显示实际端口。

### 第 3 步：搜索并下载

1. 在**搜索框**输入剧名（如「庆余年」），点 **🔍 全网搜索**（或直接按回车）
2. 等 2~5 秒，结果表格出现，可按 类型 / 地区 / 年代 / 集数 查看
3. 点某条资源的 **「剧集」** 按钮展开全部集数 → **点某一集**即开始下载
4. 下方 **「下载队列」** 显示进度条、速度、剩余分片；完成后点 **「打开文件」** 直接播放

## 三、下载设置详解

### 并发线程（默认 16）

同时下载的分片数。数值越大越快，但对资源站压力也越大：

| 数值 | 适用场景 |
|------|----------|
| 4~8 | 网络不稳 / 资源站限流，最稳 |
| **16** | 默认，速度与稳定兼顾 |
| 32~64 | 带宽充足、追求速度；部分站点可能拒连 |

### 用 ffmpeg 转 MP4

勾选后，下载完成的 `.ts` 会自动**无损转封装**为 `.mp4`（不重新编码，画质零损失，几十秒完成）。

- 转成功 → 只保留 `.mp4`（体积通常略小）
- 转失败 → 保留 `.ts`，队列里会提示原因，不影响观看

### 下载后自动转换

不勾选的话，无论 ffmpeg 是否就绪都只输出 `.ts`。**如果你只想收藏 ts 原始流，或想自己用播放器处理，可以取消勾选。**

## 四、关于 ffmpeg（可选但推荐）

ffmpeg **不是必须的**——没有它也能正常下载，只是产物是 `.ts` 格式（PotPlayer / VLC / MPV 都能直接播放）。

想要 MP4 的话，有三种办法让程序找到 ffmpeg：

### 方法 A：放到程序旁边（最简单）

```
D:\M3U8下载器\
├── M3U8下载器.exe
└── ffmpeg\
    └── bin\
        └── ffmpeg.exe      ← 放这里，程序自动识别
```

也支持这几个位置，程序会依次查找：

```
程序目录\ffmpeg.exe
程序目录\ffmpeg\ffmpeg.exe
程序目录\ffmpeg\bin\ffmpeg.exe
程序目录\bin\ffmpeg.exe
```

### 方法 B：加进系统 PATH

把 ffmpeg 的 `bin` 目录加到系统环境变量 `PATH`，重启程序即可。

### 方法 C：界面里手动填

「下载设置」→ **ffmpeg 路径** 输入 `ffmpeg.exe` 的完整路径（例如 `D:\tools\ffmpeg\bin\ffmpeg.exe`）→ 点 **保存路径**。会记到程序目录的 `ffmpeg.json`，下次自动读取。

### 下载 ffmpeg

官网 <https://ffmpeg.org/download.html> → Windows 版 → 选 `ffmpeg-release-essentials.zip`（约 80MB）→ 解压即得 `ffmpeg.exe`，绿色免安装。

## 六、常见问题

### Q1：双击后窗口一闪就没了？

多半是端口全被占用。改成命令行启动看具体错误：

```cmd
M3U8下载器.exe --port 9123
```

也可以换端口：`--port 9000`。加上 `--no-browser` 则不自动开浏览器。

### Q2：浏览器打不开页面？

看黑窗口里打印的地址（形如 `http://127.0.0.1:8899/`），复制到浏览器手动打开。若提示拒绝连接，说明程序已退出，请重开。

### Q3：搜不到我想看的剧？

- 试试**换关键词**：去掉「第一季」「2024」等后缀，只留剧名主体
- 多勾选几个资源站（默认已勾 7 个可搜索的）
- 「闪电 / 天涯 / 无水印」三个接口**本身不支持关键词搜索**（点它会有提示），这是接口方的限制

### Q4：下载中途大量失败？

- 把**并发线程调小**到 4~8 再试
- 换个资源站的同一部剧（不同站点片源不同）
- 有些剧集链接会失效，点「检测」先验一下

### Q5：下载很慢？

速度主要取决于资源站 CDN。可以：
- 增加并发线程（16 → 32）
- 换一个资源站的结果（光速/量子通常较快）
- 避开晚上高峰

### Q6：能不能边下边播？

可以。下载中的 `.ts` 是**顺序写入**的，用 PotPlayer 打开该文件即可从已下部分开始播放（播放器需支持"文件增长时继续读取"）。更推荐用列表里的「检测」，拿到 m3u8 链接后直接丢给 PotPlayer。

### Q7：杀毒软件报毒？

PyInstaller 打包的未签名 EXE 常被误报。程序**完全开源**（源码同仓库），你可以：
- 自行查看全部源码后重新打包（见 README）
- 或直接运行 Python 源码版，不使用 EXE

### Q8：下载的文件在哪？

默认在 `程序目录\downloads\`，界面「下载设置」里有完整路径和「打开目录」按钮。也可以用 `--out` 指定：

```cmd
M3U8下载器.exe --out D:\影视\庆余年
```

### Q9：怎么彻底卸载？

程序**不写注册表、不装服务**，删除文件夹即卸载完毕（`downloads` 里是下载的文件，按需保留）。

## 八、文件说明

运行后程序目录会长这样：

```
D:\M3U8下载器\
├── M3U8下载器.exe          ← 程序本体（唯一必需文件）
├── sources.json            ← 资源站配置（可选，放旁边可覆盖内置配置）
├── ffmpeg.json             ← 保存的 ffmpeg 路径（界面点"保存路径"后生成）
└── downloads\              ← 下载的影视文件 + 导出的表格
```

**想自定义资源站**：把 `sources.json` 放到 EXE 旁边，按下面格式增删即可（改完重启程序）：

```json
{
  "sources": [
    { "id": "mysite", "name": "我的站点",
      "api": "https://example.com/api.php/provide/vod",
      "search": true,
      "note": "备注文字" }
  ]
}
```

`search: false` 表示该接口不支持关键词搜索（只在界面上显示、不参与聚合）。
